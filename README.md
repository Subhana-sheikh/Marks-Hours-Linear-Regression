# Marks Prediction using Linear Regression
A Machine Learning project using Python and Linear Regression to predict students' marks based on study hours. Built and trained in Google Colab using Scikit-learn, Pandas, and Matplotlib.
## Project Overview
This project uses Linear Regression to predict student marks based on the number of study hours.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
The dataset contains study hours and corresponding marks obtained by students.

## Objective
To understand and implement the Linear Regression algorithm for predictive analysis.

## Results
The model successfully predicts marks based on study hours and visualizes the relationship between the variables.
